# Artlist Web Unlimited Skills

Two Codex skills for generating images and videos through the Artlist website in Unlimited mode.

## Included skills

- `artlist-web-unlimited-image/` — Artlist web image generation and editing.
- `artlist-web-unlimited-video/` — Artlist web video generation.

Copy either skill folder into your Codex skills directory to use it. These workflows rely on browser control and the currently signed-in Artlist account. Unlimited availability and generation settings can change; verify the website before submitting.
